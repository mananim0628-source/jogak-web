# 번외 — love-animal-test 재설계 검증 자료
> 질문: love-animal-test(연애 동물 테스트, MBTI+사주)를 최신 트렌드에 맞춰 재설계하면?
> 방식: 추론 아닌 레퍼런스 검증. 결론은 "엔진은 정답, 포지션·수익모델이 약점".
> ⚠️ 신규 프로젝트로 실행할지는 **보류** — 이 문서는 판단용 자료.

## 사실 보정
"살아있는 유료 제품"이라 했던 건 배포(Vercel)+결제 CTA가 박혀 있다는 의미. 트래픽·매출이 도는 건 아님.
초반 배포 후 멈춘 **"만들어두고 잠든 자산"** → 지킬 매출 없음 = 재활용 자유도 높음.

## 검증 요약 (4)
**1) 포맷은 정답 — 밸런스게임+라벨링은 현재도 바이럴 메인**
- 푸망 밸런스게임: 썸 밸런스 34.9만 / 신년 종합운세 8.6만 플레이. 각 테스트에 저장·공유·"재밌어요/정확해요"·댓글 기본 탑재. (출처: poomang.com)
- 심리테스트 = "자발적 참여+인지도"의 바이럴 묘책. (출처: 캐릿 careet.net)
→ 우리 10문항 A/B 밸런스게임 구조는 검증된 포맷. 버릴 게 아님.

**2) 수익모델이 약점 — 직접 결제(5천/3천원)는 가장 어려운 길**
- 실제 돈은 B2B: 푸망 누적 7,500만 플레이·360건+, CJ ENM·디즈니·AK몰·에이블리 협업. 풀패키지·최소 5만 플레이 보장. **결과 페이지 = 광고 지면.** (출처: i-boss, 유니콘팩토리)
- W컨셉: 2주 18만 플레이. "추구미 유형 → 행운 아이템 추천 → 쿠폰"으로 광고처럼 안 느껴지게 전환. (출처: i-boss)
- 이용자 25~34세 35% 등 전 세대 분포. 배너보다 효과적. (출처: 유니콘팩토리)
→ 돈은 **"결과→추천→전환" + 도달(트래픽)**에서 남. 단품 심층풀이 결제 ❌.
   단품 결제는 콘텐츠·브랜드 쌓인 대형 사주앱(포스텔러 860만/85억)에서만 통함.

**3) AI 개인화 = 2026 신선한 차별점**
- 점신: AI+사주 알고리즘, AI 관상·심리테스트, 운세→복주머니→실제 상품·부적 굿즈. (출처: Google Play)
- 헬로우봇: AI 챗봇 상담, 2만 자 보고서, 누적 다운 1위·40만 판매. (출처: App Store)
- 사주팔자AI: Haiku/Gemma 모델 선택형 AI 사주. (출처: mobidicsaju.com)
→ 정적 결과 텍스트 → **Claude Haiku 맞춤 풀이**로 업그레이드. (navcp에서 이미 Haiku 사용 중 = 즉시 가능)

**4) "연애·궁합" 니치는 포화**
- 푸망에 연애 심리 테스트 빽빽(엔딩·불륜 지수·멘헤라 등). "또BTI" 식상함도 실재. (출처: poomang, 고구마팜)
→ 일반 "연애 동물 테스트"로는 묻힘.

## 종합 판정
**단품 B2C 유료 연애 동물 테스트 재론칭 = 약한 베팅.** (포화 니치 + 가장 어려운 결제 모델 + 솔로엔 없는 B2B 도달)

**트렌드 정답 = "엔진 살리고 3개 변경"**
1. 니치 재테마(포화 회피) + 결과에 **행동 전환** 내장(추천→쿠폰/모임).
2. 결과 레이어 **AI화**(Haiku 맞춤 풀이) + 무료 라벨링 / freemium 심층.
3. 수익은 **도달 기반**(추천·제휴·시즌 스파이크), 단품 결제 ❌.
