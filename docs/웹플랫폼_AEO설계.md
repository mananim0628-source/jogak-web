# 조각닷컴 웹 플랫폼 + AEO/GEO/SEO 설계도
> 목표: 인스타(유입 깔때기) → **웹 본체(검색·AI 자산 + 앱 경험)** 로 플랫폼화.
> 근거: 2026 GEO/SEO 모범사례 + Next.js 렌더링 검증(추론 아님).

## 0. 핵심 원리 (검증됨)
- **PWA는 SEO에 불리하지 않다. 적은 CSR이다.** 크롤러는 JS를 완전 실행 안 함 → CSR 콘텐츠/메타는 색인 약함.
- **해법 = Next.js 하이브리드**: 콘텐츠는 SSG/ISR(서버 렌더=검색 자산), 유저별 페이지는 CSR(앱 경험). PWA는 그 위 레이어.
- **GEO는 SEO 위에서 작동.** SEO 먼저 탄탄히 → AI 인용 따라옴.
- **AI "순위 보장"은 불가/사기성.** 우리는 인용 "확률"을 품질·구조로 높인다.

## 1. 기술 스택 (확정 추천)
**Next.js(App Router) + Supabase + Vercel + PWA 레이어** — navcp와 동일.
- 이유: 운영 경험 보유 / Vercel이 SSR·ISR 인프라 자동 / Supabase 이미 사용 / 새 학습비용 0.
- 렌더링 정책:
  | 페이지 | 방식 | 이유 |
  |---|---|---|
  | 가이드 아티클(EP) | **SSG/ISR** | 검색·AI 색인 대상, 자주 안 바뀜 |
  | 홈/카테고리 | SSG/ISR | 색인 + 빠른 로딩 |
  | 회원/마이페이지 | CSR | 유저별, SEO 불필요 |
  | 나이트타입 테스트 | CSR | 인터랙션 중심 |
  | 모임 매칭 | CSR/SSR 혼합 | 유저별 |
- ⚠️ SSR 주의: `window`/`localStorage` 등 브라우저 객체는 서버 렌더 시 가드 필요(없으면 렌더 실패).

## 2. 단계적 로드맵 ("둘 다 단계적으로")

### Stage 1 — 검색·AI 자산 (먼저)
**목표**: EP 콘텐츠를 검색·AI에 잡히는 웹 자산으로.
- 가이드 허브 `/guide/[slug]` (SSG/ISR). EP.01 = "강남 클럽 처음 가이드"가 첫 아티클.
- **아티클 구조 (AEO/GEO 친화)**:
  1. 질문형 H1/H2 ("강남 클럽 처음 갈 때 비용은 얼마?")
  2. **정의/답 먼저** ("강남 클럽 테이블은 보틀 정가 + 테이블 차지로, 보통 100만원+다") → AI 인용 적합
  3. 비용 **표**(보틀/테이블/1인 분담)
  4. **FAQ 섹션 + JSON-LD(FAQPage) 스키마**
  5. 내부링크(다른 가이드) + E-E-A-T(작성자·출처·실제 경험 명시)
  6. CTA: @jogakdotcom / 가입 대기
- **기술 SEO**: 서버 렌더 메타·OG, sitemap.xml, robots.txt, 구조화 데이터(Article/FAQPage/BreadcrumbList).
- **등록**: 구글 서치콘솔 + **네이버 서치어드바이저**(한국 타깃 필수).
- **파이프라인 변경**: EP 제작 워크플로에 **"웹 아티클 산출" 단계 추가** → 인스타(릴스·카드) + 웹(아티클) 1편 동시 3채널.

### Stage 2 — 앱 경험 (검색 자산 쌓인 뒤)
- 회원/로그인: Supabase Auth.
- **나이트타입 테스트 흡수**(봉인된 잠든 자산 → /test, T4 유입).
- **모임 매칭**: [[CLAUDE_조각닷컴]] Phase 3 + 이미 설계한 멤버십·평판 스키마 적용.
- **PWA**: 설치 프롬프트, 오프라인 셸, 푸시(navcp 알림 3종 구조 참고).

## 3. 이미 만든 자산과의 수렴 (재사용)
| 기존 산출물 | 플랫폼에서의 역할 |
|---|---|
| 멤버십·평판 스키마(.sql) | Stage 2 백엔드 (모임·평점·뱃지) |
| 나이트타입 테스트(봉인) | Stage 2 T4 유입 자산 (/test) |
| EP 콘텐츠 + 콘텐츠트랙 | Stage 1 가이드 아티클 소스 |
| 제목30 클린재작성 | 가이드 주제·질의어 뱅크 |
| 스카우터 v2 | 질의어/트렌드 → 아티클 주제 자동 |
→ 따로 만든 게 아니라 한 플랫폼의 부품. 새 빌드 최소화.

## 4. 측정 (순위 보장 아님)
- SEO: 서치콘솔/서치어드바이저 색인·노출·클릭.
- AEO/GEO: 주요 질의어를 ChatGPT/Perplexity/Gemini·구글 AI Overview에 직접 물어 **인용 여부 수동 추적**(주기적).
- 전환: 아티클 → @jogakdotcom/가입 유입.

## 5. ⚠️ 착수 전 결정할 것 (빌드 전 합의)
1. 도메인 — 정식 도메인 확보할지(브랜드+SEO 유리) vs Vercel 기본.
2. Stage 1 MVP 범위 — 가이드 아티클 몇 편으로 시작?(EP.01~03 정도)
3. 콘텐츠 우선 — 지금은 **EP 인스타 발행 리듬**도 진행 중. 웹 빌드와 우선순위 조정 필요.
4. navcp 리소스 분배 — 두 프로젝트 동시 진행 부하.

> 주의: 이건 큰 빌드다. 나이트타입처럼 "하는 김에" 끌려가지 말 것.
> Stage 1 MVP 범위를 좁게 확정하고 착수. EP 발행(본류)과 병행 우선순위 합의 후 시작.
