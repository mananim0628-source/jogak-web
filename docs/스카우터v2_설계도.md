## 0. 왜 입력단부터인가
파이프라인 순서 = **스카우터(입력) → 콘텐츠기획자 → 제작자(카드/숏폼) → 영상생성자 → 통합봇**.
입력 신호가 빈약하면 뒤의 점수화·3트랙 자동선택이 "재료 없는 상태"가 됨.
지금 단일 web_search로는 **팝업 클럽·라운지 클럽·파일럿 릴스** 같은 신호가 정량으로 안 잡힘 → 소스 확장이 최대 레버리지.

## 1. 아키텍처 (v1 → v2)
```
[v1]  Trigger → Claude(web_search) → 콘텐츠기획자

[v2]  Trigger(cron + @jagak_bot 수동)
        ├─ A. 네이버 데이터랩 API      (정량: 키워드 검색량 추세)
        ├─ B. 구글 트렌드(VPS pytrends) (정량: 급상승 쿼리)
        ├─ C. 시즌/이벤트 캘린더        (타이밍: 연휴·시즌·페스티벌)
        └─ D. Claude(web_search)        (정성: 포맷·주제 트렌드 요약)
                         ↓ Merge
                 [Code] 정규화 → 통합 시그널 스키마
                         ↓
                 [Code] 점수화·랭킹 + 금지어 태깅 + 트랙/포맷 추천
                         ↓
              ├─ Supabase 로그 (trend_signals 테이블)
              └─ 콘텐츠기획자 워크플로로 표준 JSON 전달
```

> ⚠️ N8N MCP는 노드 **편집 불가(조회·실행만)**. 실제 노드 배선은 N8N UI에서.
> 호스트 curl로 워크플로 업데이트 시 **PUT**(PATCH 아님), Code 노드 env는 `$env['KEY']`,
> Docker `N8N_BLOCK_ENV_ACCESS_IN_NODE=false`, UI는 PUT 후 **하드리프레시(Ctrl+Shift+R)**.

## 3. 소스별 노드 구성

### A. 네이버 데이터랩 (정량, 무료)
- 노드: **HTTP Request** (POST `https://openapi.naver.com/v1/datalab/search`)
- 헤더: `X-Naver-Client-Id: {{$env.NAVER_ID}}`, `X-Naver-Client-Secret: {{$env.NAVER_SECRET}}` ← env 필수
- 바디 예시:
```json
{
  "startDate": "{{ $now.minus(28,'days').format('yyyy-MM-dd') }}",
  "endDate": "{{ $now.format('yyyy-MM-dd') }}",
  "timeUnit": "week",
  "keywordGroups": [
    {"groupName":"강남클럽","keywords":["강남클럽","강남 클럽"]},
    {"groupName":"라운지","keywords":["강남 라운지","압구정 라운지"]},
    {"groupName":"오마카세","keywords":["강남 오마카세"]},
    {"groupName":"루프탑","keywords":["루프탑바","강남 루프탑"]}
  ]
}
```
- 산출: 그룹별 주차 ratio 배열 → 최근 추세 기울기로 momentum 일부 산출.

### B. 구글 트렌드 (정량, VPS pytrends)
- N8N에 공식 API 없음 → **VPS Flask 엔드포인트** 추가 후 HTTP Request로 호출.
- 엔드포인트(VPS, 158.247.238.32): `/trends?kw=강남클럽,강남라운지`
- Flask 스니펫(요지):
```python
from flask import Flask, request, jsonify
from pytrends.request import TrendReq
app = Flask(__name__)
@app.get("/trends")
def trends():
    kws = request.args.get("kw","").split(",")[:5]
    py = TrendReq(hl="ko-KR", tz=540)
    py.build_payload(kws, timeframe="today 1-m", geo="KR")
    interest = py.interest_over_time().drop(columns=["isPartial"], errors="ignore")
    rising = {}
    try:
        rq = py.related_queries()
        for k in kws:
            r = (rq.get(k) or {}).get("rising")
            rising[k] = r.to_dict("records")[:5] if r is not None else []
    except Exception: pass
    return jsonify({"interest": interest.tail(4).to_dict("records"), "rising": rising})
```
- pm2로 등록(기존 jogak 스크립트와 동일 패턴), 포트는 기존 Flask와 분리.

### C. 시즌/이벤트 캘린더 (타이밍)
- 옵션 1: **Code 노드 정적 JSON** (연휴·시즌 파티·페스티벌 날짜 테이블) — 간단, 추천 시작점.
- 옵션 2: **Google Calendar**(이미 연결됨) 노드로 향후 이벤트 pull.
- 산출: 임박 이벤트(7~14일 내)면 관련 카테고리 momentum +보정, timing_hint 생성.

### D. Claude web_search (정성)

## 4. 점수화·랭킹 Code 노드 (핵심 JS)
```javascript
// 입력: A(datalab), B(pytrends), C(calendar), D(websearch) merge 결과
// 출력: 표준 스키마 signals[] + top_pick
const FORBIDDEN = ["룸살롱","풀살롱","텐프로","마담","호스티스","도우미",
  "2차","풀","옵션","유흥","접대부","에스코트","시세","호구"]; // 클린 검증

function slopePct(arr){ // 최근 추세 기울기(%) — datalab ratio 배열
  if(!arr || arr.length<2) return 0;
  const a = arr[0], b = arr[arr.length-1];
  return a ? Math.round(((b-a)/a)*100) : 0;
}
function cleanCheck(text){
  const hit = FORBIDDEN.find(w => (text||"").includes(w));
  return { ok: !hit, hitWord: hit||null };
}

const datalab = $('데이터랩').first().json || {};
const trends  = $('구글트렌드').first().json || {};
const cal     = $('시즌캘린더').first().json || {};
const web     = $('웹서치').first().json || {};   // {topics:[{topic,category,track,format,note}]}

const out = [];
for (const t of (web.topics || [])) {
  const cat = t.category;
  // 정량 momentum: datalab 기울기(0.5) + pytrends rising 수(0.2) + web 가중(0.2) + 타이밍(0.1)
  const dl = (datalab.results||[]).find(r => r.title?.includes(t.keyword||t.topic));
  const dlSlope = dl ? slopePct((dl.data||[]).map(d=>d.ratio)) : 0;
  const rising = ((trends.rising||{})[t.keyword]||[]).length;
  const upcoming = (cal.upcoming||[]).some(e => e.category===cat);
  let m = 0;
  m += Math.max(0, Math.min(50, dlSlope));            // 0~50
  m += Math.min(20, rising*4);                         // 0~20
  m += (t.web_weight ?? 15);                           // 기본 15
  m += upcoming ? 10 : 0;                              // 타이밍 +10
  const clean = cleanCheck(`${t.topic} ${t.note||""}`);
  out.push({
    topic: t.topic, category: cat,
    sources: ["datalab","pytrends","websearch"].filter((_,i)=>[dl,rising,true][i]),
    momentum: Math.round(m),
    evidence: `데이터랩 ${dlSlope>=0?'+':''}${dlSlope}% · 급상승 ${rising}건${upcoming?' · 임박이벤트':''}`,
    suggested_track: t.track || "info",
    suggested_format: t.format || "card",
    timing_hint: upcoming ? "임박 이벤트 전 발행" : "주말 전 목요일",
    clean_flag: clean.ok
  });
}
out.sort((a,b)=> b.momentum - a.momentum);
const signals = out.filter(s => s.clean_flag);          // 금지어 포함 후보 제외
return [{ json: {
  generated_at: new Date().toISOString(),
  signals,
  top_pick: signals[0] || null
}}];
```

## 6. Supabase 로그 테이블 (trend_signals)
```sql
create table public.trend_signals (
  id           uuid primary key default gen_random_uuid(),
  generated_at timestamptz not null default now(),
  topic        text not null,
  category     text not null,
  momentum     smallint not null,
  evidence     text,
  suggested_track  text,
  suggested_format text,
  timing_hint  text,
  used         boolean not null default false,   -- 콘텐츠로 채택됐는지
  created_at   timestamptz not null default now()
);
-- write = service_role only (navcp 컨벤션)
alter table public.trend_signals enable row level security;
create policy ts_no_client_write on public.trend_signals
  for all to anon, authenticated using (false) with check (false);
```
→ 채택률(used) 추적 시 향후 momentum 가중치 자율 보정 가능.
